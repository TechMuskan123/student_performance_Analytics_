# Student Performance Analytics System

A Python-based student performance analysis project using Pandas and NumPy.

## Technologies
- Python
- Pandas
- NumPy

## Files
- `student_performance.py` - main Python program
- `students.csv` - student dataset
- `requirements.txt` - required Python libraries

## Main Features
- Load student data using Pandas
- Calculate total and average marks
- Assign grades
- Identify Pass/Fail students
- Find highest, lowest and class-average performance
- Show top performers
- Analyse subject-wise and department-wise performance

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Install libraries:
   `pip install -r requirements.txt`
4. Run:
   `python student_performance.py`
